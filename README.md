# 🎵 Spotify Clone

A simple **Spotify Clone UI** created using **HTML and CSS** while learning and practicing frontend web development.

## 📌 About the Project

This project is a beginner-level recreation of the Spotify web interface.  
I built it to practice the fundamentals of **HTML and CSS**, including page structure, layouts, styling, images, and responsive design.

> **Note:** This is a frontend practice project and does not include Spotify's actual music streaming functionality.

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Features

- Spotify-inspired user interface
- Navigation sidebar
- Music/playlist sections
- Album and song cards
- Play button UI
- Music player section
- Responsive styling
- Clean and simple layout

## 🚀 How to Run

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder.

3. Open `index.html` in your browser.

That's it! 🎧
